##  Diabetes Prediction & Exploratory Data Analysis

This project focuses on exploratory data analysis (EDA) and machine learning model implementation using the diabetes binary classification dataset to predict diabetes status based on health survey indicators.

##  Dataset Overview
- **Dataset Name:** `diabetes_binary_5050split_health_indicators.csv`
- **Target Variable:** `Diabetes_binary` (Binary classification: `0` for no diabetes, `1` for prediabetes or diabetes).
- **Features:** Includes various health indicators such as High Blood Pressure, High Cholesterol, BMI, Smoking status, Physical Activity, and more.

##  Tech Stack & Libraries
- **Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn

##  Repository Structure
├── Diabetes prediction binary_balance.ipynb            # Jupyter Notebook containing EDA & ML models
├── diabetes_binary_5050split_health_indicators.csv     # Dataset file
└── README.md                                           # Project documentation


##  Key Steps Performed
1. **Data Loading & Inspection:** Loaded the dataset using `pandas` and checked data types, missing values, and summary statistics.
2. **Exploratory Data Analysis (EDA):** Visualized distributions and correlations between various risk factors and diabetes.
3. **Model Preparation:** Prepared data for classification algorithms.
